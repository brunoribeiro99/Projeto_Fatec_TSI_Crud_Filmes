Sobre o Projeto de Filmes

Este projeto tem como finalidade apresentar um catálogo de filmes, exibindo informações como título, gênero e uma breve descrição de cada obra.

A ideia surgiu a partir do meu interesse por filmes, principalmente pelo gênero de comédia. Por isso, o catálogo possui alguns filmes desse gênero, como Se Beber, Não Case!, American Pie: Beta House e Mac & Devin no Colegial.

Além das comédias, também foram adicionados filmes de outros gêneros, como ação e ficção científica, representados por títulos como John Wick 4: Baba Yaga e Matrix Resurrections.

O projeto foi desenvolvido utilizando HTML e CSS, com o objetivo de praticar a criação de páginas web, organização de conteúdo, estruturação de elementos e estilização de uma interface inspirada em plataformas de streaming.
